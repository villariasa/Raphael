## <img src="icons/cpu-chip.svg" width="22" height="22" align="center" /> Core Philosophy & Architecture

Most autonomous AI agents execute shell commands and file operations blindly in the background or send your entire screen and keystrokes to remote servers. **Raphael takes an enterprise-grade, local-first approach:**

1. <img src="icons/lock-closed.svg" width="16" height="16" align="center" /> **100% Local Intelligence** — Driven by local LLMs via [Ollama](https://ollama.com/) (e.g. `llama3.1`, `mistral`, or custom quantized models). No sensitive data leaves your machine.
2. <img src="icons/shield-check.svg" width="16" height="16" align="center" /> **Safe Action Model (SAM)** — Actions generated by the planner must strictly conform to a typed schema validated by `Zod`. Unvalidated commands are rejected before execution.
3. <img src="icons/check-badge.svg" width="16" height="16" align="center" /> **Granular Permission Gate** — Every action is categorized by risk (`low`, `medium`, `high`). Destructive or system-level actions trigger interactive modal approval (`Allow Once`, `Always Allow`, `Deny`).
4. <img src="icons/eye.svg" width="16" height="16" align="center" /> **Visual Cursor & Feedback Overlay** — Non-intrusive transparent HUD overlay that displays cursor trajectories and visual indicators during automated tasks.
5. <img src="icons/pause-circle.svg" width="16" height="16" align="center" /> **Task Control & Audit Trails** — Real-time progress display, step-by-step task tracking, instantaneous `Pause` / `Resume` / `Abort` capability, and persistent activity logging.

## <img src="icons/cube.svg" width="22" height="22" align="center" /> Technical Stack

- **Desktop Framework:** Electron 32 + Node.js (with secure Context Isolation & sandboxed renderers)
- **Frontend / UI:** React 18, Vite 5, Tailwind CSS
- **Type Safety & Contracts:** TypeScript 5.5, Zod Runtime Validation
- **Local AI Provider:** Ollama Local API (`http://localhost:11434`)
- **Packaging:** electron-builder (NSIS installer for Windows, Linux AppImage/tar.gz)

## <img src="icons/rocket-launch.svg" width="22" height="22" align="center" /> Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Ollama](https://ollama.com/) installed and running locally with your desired model:
  ```bash
  ollama run llama3.1
  ```

### Installation

```bash
# Clone the repository
git clone https://github.com/villariasa/Raphael.git
cd Raphael

# Install dependencies
npm install
```

### Development Mode

Run the dual-process dev environment (Vite renderer + TypeScript main watcher):

```bash
# In terminal 1: Start renderer
npm run dev:renderer

# In terminal 2: Build main process and launch Electron
npm run start
```

### Production Packaging

```bash
# Build desktop executable (Windows NSIS)
npm run dist:win

# Universal production build
npm run build
```

## <img src="icons/table-cells.svg" width="22" height="22" align="center" /> Safe Action Matrix

| Action Kind | Risk Level | Description |
| :--- | :--- | :--- |
| `read_system_info` | **Low** | Queries OS version, architecture, and shell environment |
| `list_installed_applications` | **Low** | Enumerates installed software packages |
| `read_file` | **Low** | Reads file content without mutation |
| `create_folder` | **Medium** | Creates new directories safely within user scopes |
| `create_file` / `modify_file` | **Medium** | Safe-path file generation and modification |
| `open_application` | **Medium** | Launches registered system applications |
| `execute_command` | **High** | Terminal command execution (explicit confirmation required) |
| `modify_path` / `modify_registry` | **High** | System environment & registry modifications |
| `delete_file` | **High** | File removal operations |
